# FactorGPT 商业计划书

> 大模型驱动的智能量化因子挖掘平台 · 商业需求与商业可行性分析
> 编制日期：2026-08-08
> 数据来源：《宽邦科技：2024-25 年度中国量化投资白皮书》、公开市场研究与行业研报

---

## 一、执行摘要

FactorGPT 是一个由大语言模型（LLM）驱动的量化因子挖掘与验证平台，核心能力是把投资者的自然语言投资想法（"寻找低估值、高 ROE 且近期动量向上的股票"）自动转化为可执行的因子表达式或 Python 代码，并通过一套包含 IC、RankIC、分位数收益、多空夏普等指标的严谨回测流水线完成验证，再经"因子精炼厂"流水线（LLM 自反思 + 遗传编程优化）迭代改进，最终沉淀到因子库并支持导出部署。

本计划书结合《2024-25 年度中国量化投资白皮书》与中国量化投资的普及进程，论证 FactorGPT 的商业可行性。核心判断是：中国量化行业在 2025—2026 年进入"3 万亿时代"，但行业同时面临 Alpha 衰减、策略同质化与因子拥挤三重压力；白皮书的调研数据显示，"AI 全流程自动化"与"AI 自主生成逻辑（AutoML）"已被机构列为下一代 AI 在量化领域最可能突破的方向，且 AI 在 2025 年机构能力建设优先级中综合得分最高（5.03）。FactorGPT 的产品定位与这一行业最高优先级需求高度吻合，在开源金融 Agent 竞品普遍停留在"买卖决策聊天"层面、缺乏严格因子回测闭环的情况下，具备清晰的技术差异化与商业化空间。

## 二、产品介绍

### 2.1 产品定位

FactorGPT 是"自然语言 → 因子代码 → 严谨回测 → 精炼优化 → 因子库沉淀"的端到端闭环平台，面向"想用量化但被编程、数据、统计门槛挡在门外"的个人投资者、投研人员和中小机构，把因子工程的经验门槛从"数年量化训练"降低到"会表达投资想法"。

### 2.2 核心能力

| 模块 | 能力说明 |
|------|----------|
| 自然语言因子生成 | 将投资想法转为因子表达式 / Python 代码，支持多 LLM（OpenAI、DeepSeek、Ollama 本地模型）与设计的知识库检索增强（RAG） |
| 六阶段因子精炼厂（Refinery） | 想法拆解 → 因子构造 → 回测 → LLM 自反思诊断 → 遗传编程（GP）优化 → 再回测，自动化迭代 |
| 严谨回测体系 | 因子 IC、RankIC、ICIR、分位数分组收益、多空组合净值与夏普、换手率等机构级评价指标 |
| 因子库与遗传编程 | 已验证因子沉淀入库，支持 GP 自动变异/组合出新因子，对抗因子失效 |
| 交互式界面 | 基于 Streamlit 的可视化工作台，结果图表化呈现 |
| 知识库接入 | 支持接入腾讯 ima 等外部知识库，沉淀机构自有研究与监控订阅内容 |

### 2.3 技术栈

后端以 Python 为核心（与行业 97.12% 的 Python 主导格局一致），LLM 编排采用主流 Agent 框架思路，回测与统计沿用 Pandas / NumPy / scikit-learn 生态，并以 HF Space 形式对外提供轻量 Demo。这一技术选择与白皮书揭示的行业技术栈（Python 97.12%、scikit-learn 61%、PyTorch 49%、机器学习远高于深度学习）高度契合，降低了用户的学习与对接成本。

## 三、商业需求分析（为什么是现在）

### 3.1 行业痛点

白皮书揭示了量化行业的三重结构性矛盾，恰好构成 FactorGPT 的需求基础：

- **Alpha 衰减与策略同质化**：七成量化机构认为 A 股量化超额收益正在衰减，核心归因集中于"策略同质化与供需失衡"（占比 42.11%），其次为监管收紧（11.96%）与市场效率提升（13.40%）。当传统多因子 Alpha 遭遇瓶颈，机构不得不探索宏观、基本面、择时、出海等新方向——而快速构建多样化新因子正是 FactorGPT 的强项。
- **因子拥挤与失效加速**：白皮书将"因子拥挤度测算"列为机构中长期系统优化的优先动作（20.14%），因子有效性半衰期缩短，持续产出新因子的能力成为竞争壁垒。
- **人才与门槛壁垒**：白皮书指出出海最大障碍依次为市场规则差异（51.59%）、策略水土不服（42.06%）、人才（41.27%）与通道（38.1%）。在境内，"会 Python、懂统计、有数据"的复合型人才稀缺，中小机构与个人难以负担完整量化团队。

### 3.2 需求拐点：AI 成为机构第一优先级

白皮书连续四年调研均显示 AI 是量化机构最重要的研究方向之一；2024 年 DeepSeek 出圈后，AI 重要性被提到空前高度——在 2025 年机构各项能力建设优先级中，AI 综合得分最高（5.03），且在"第一位选择"中占比 29.69%。

白皮书进一步设问"下一代 AI 最可能突破的量化领域"，归纳出五大趋势方向：**模态数据融合、全流程自动化、高频交易智能化、智能择时与动态调仓、可解释性与动态风控**。所有这些方向共同指向"输入数据的广义化"与"决策权让渡给机器"，即从人工制定规则走向 **AI 自主生成逻辑（AutoML）**。FactorGPT 的本质正是"AI 自主生成因子逻辑 + 全流程自动化验证"，直接命中行业第一优先级需求，而非锦上添花。

## 四、市场分析

### 4.1 中国量化市场规模与增长

| 口径 / 时间 | 规模 | 备注 |
|------|------|------|
| 2024 年股票量化私募 AUM | 约 1.40 万亿元 | 占整体私募市场 26.35%（2023 年末为 28.96%），经历"收缩—再扩张"波动 |
| 2024 年全市场量化规模 | 约 1.43 万亿元 | 私募量化约 8370 亿 + 公募量化近 3000 亿 + 其他约 2000 亿 |
| 2025 年末 | 全市场量化超 2 万亿元 | 指数增强约 1.19 万亿（占量化策略近 40%）、股票中性约 0.74 万亿、量化选股约 0.54 万亿 |
| 2026 年一季度 | 量化私募总量约 2.8 万亿元 | 正式迈入"3 万亿时代"；百亿级量化私募达 71 家（截至 2026 年 4 月底） |
| 成交占比 | 量化占 A 股总成交额 30%–32% | 中证 2000 等小微盘个股中量化成交占比普遍超 50% |

数据来源：宽邦科技《2024-25 年度中国量化投资白皮书》、中信证券 / 浙商证券研报、私募排排网、东财测算。

### 4.2 普及与结构性趋势

- **渗透率仍有空间**：中国量化成交占 A 股约三成，相较美国被动及量化策略更高的成熟度，仍有提升空间；白皮书显示股票、期货、期权、债券四类资产的量化参与率连续三年上升（分别 +7.80%、+13.44%、+3.88%、+3.27%）。
- **中低频化与多资产**：2024 年行业整体"降频、中频强化、高频收缩"，并向期货、期权、债券多资产延展，对灵活构建新因子工具的需求上升。
- **监管重塑下的规范化**：2024 年"监管"一词在调研数据中出现频率最高（超 50 次），私募新规、程序化交易限制、DMA 收紧落地；长期看"扶优限劣"利于规范化头部与合规工具发展，FactorGPT 作为合规的研究辅助工具（非自动交易执行）契合监管导向。
- **出海与本地化痛点**：六成机构有出海计划但多数处于早期；市场规则与数据结构差异（51.59%）是最大障碍，凸显"可快速适配不同市场数据、自动生成本地化因子"的工具价值。

### 4.3 目标市场测算

以"量化参与率上升 + 中小机构/个人投研工具缺口"为锚：2025 年全市场量化超 2 万亿、百亿量化私募 71 家，但绝大多数增量资金与策略能力建设仍集中在头部；尾部出清、新锐突围并行的格局下，大量中小私募、券商投顾、高净值个人与财经院校存在"低成本、低门槛因子研究工具"的空白需求。这是一个被现有云服务（BigQuant、RiceQuant、JoinQuant 等高客单价 / 学习曲线陡峭）与开源"决策聊天机器人"（缺乏回测闭环）双向覆盖不足的市场。

## 五、适用场景

1. **个人投资者的想法验证**：把"我觉得低波动率且高分红的股票长期表现好"这类朴素想法，几分钟内变成可回测因子并看到 IC 与多空夏普，降低试错成本。
2. **中小私募 / 投顾的因子工厂**：研究人力有限时，用 FactorGPT 批量生成候选因子，研究员只需做终审与合规把关，提升因子产出效率。
3. **机构的新因子探索与对抗同质化**：在 Alpha 衰减、因子拥挤背景下，快速试验宏观、基本面、舆情、事件型等非传统因子（白皮书显示 25.84% 机构增加基本面数据、22.49% 增加事件型数据使用）。
4. **教学与投研培训**：财经院校、量化培训场景中用作"从想法到因子"的可视化教学工具。
5. **研究知识沉淀**：结合外部知识库（如腾讯 ima 订阅库），把研究员日常阅读的行业资料转化为可验证因子假设。

## 六、竞品分析（开源金融 Agent 项目）

下表对比当前 GitHub 上较有代表性的开源 LLM/多智能体金融项目：

| 项目 | GitHub | 定位 | 核心能力 | 与 FactorGPT 差异 |
|------|--------|------|----------|-------------------|
| AI Hedge Fund（virattt / ai-hedge-fund） | github.com/virattt/ai-hedge-fund | 多智能体投资决策框架 | 模拟分析师/交易员/风控角色给出买卖建议；Star 数极高（约 1.8 万+） | 偏"决策聊天"，缺乏严格因子回测（IC/多空夏普）闭环，定位研究/教育 |
| TradingAgents（TauricResearch） | github.com/TauricResearch/TradingAgents | 多智能体交易框架 | 基本面/情绪/技术分析师 → 交易员 → 风控协作决策；有论文支撑 | 聚焦交易决策流程，非因子自动生成与统计验证 |
| FinRobot（AI4Finance-Foundation） | github.com/AI4Finance-Foundation/FinRobot | 金融分析 Agent 平台 | 金融思维链（CoT）、股票研究、报告生成；已推桌面版 | 偏研究与报告自动化，无因子回测引擎 |
| FinAgent / FinGPT（AI4Finance） | github.com/AI4Finance-Foundation | 多模态交易 Agent / 金融大模型 | 多模态数据、金融 LLM 微调 | 以交易信号与模型微调为主，因子工程闭环弱 |
| QuantAgent | — | 多智能体量化框架 | 含高频交易（HFT）变体 | 面向专业机构高频场景，门槛高、非低代码 |
| 传统量化框架（vn.py / RQAlpha / QUANTAXIS / BigQuant 等） | 各官方仓库 | 回测/交易引擎、云平台 | 成熟回测与交易，但需手写策略、无 LLM 自动生成 | 功能强但门槛高，不解决"想法→代码"的生成问题 |

**竞品格局结论**：开源金融 Agent 的主流范式是"用 LLM 模拟投资团队做买卖决策"，普遍短板有三——（1）缺乏 IC/RankIC/分位数/多空夏普等机构级因子验证；（2）回测常存在前视偏差与代码幻觉风险；（3）产出停留在信号建议，难以沉淀为可复用因子资产。FactorGPT 以"因子自动生成 + 严谨回测 + 精炼迭代 + 因子库沉淀"形成差异化，正好补齐行业最需要的"全流程自动化"与"AI 自主生成逻辑"环节。

## 七、用户画像

**画像 A：进阶个人投资者 / 财经内容创作者（"想法很多、代码不够"）**
特征：有市场感觉与投资逻辑，但 Python/统计基础薄弱；时间有限、不愿搭建复杂环境。痛点：好想法无法快速验证。诉求：低门槛、可视化、能直接看到回测结果。付费意愿中等，适合订阅制轻量版。

**画像 B：中小私募 / 券商投顾研究员（"人力少、产能要上去"）**
特征：具备量化基础，团队 1–5 人，研究产能是瓶颈；面临 Alpha 衰减与因子拥挤压力。痛点：新因子产出慢、同质化严重。诉求：批量生成候选因子 + 团队因子库 + 合规可追溯。付费意愿高，适合团队/企业版。

**画像 C：量化培训 / 高校师生（"教学要直观"）**
特征：教学或科研场景，需要把"投资想法→因子→回测"全流程可视化。诉求：可解释、可演示、成本低。适合教育授权 / 开源社区版引流。

**画像 D：大型机构量化团队（"探索 AI 提效"）**
特征：已有成熟回测与因子体系，关注如何用 LLM 提效、对抗策略同质化。诉求：私有化部署、对接自有数据与知识库、可解释性与风控。付费能力最强，适合私有化/API 授权。

## 八、实用价值

- **降本提效**：把"想法→因子→回测"从数天/数周压缩到分钟级，单人即可完成过去需小团队支撑的因子探索。
- **对抗同质化**：AI 自主生成多样因子，缓解白皮书指出的"策略同质化与供需失衡"（42.11%）这一最大归因。
- **降低门槛**：非程序员也能参与量化研究，扩大量化人才供给，呼应行业人才瓶颈（41.27%）。
- **知识资产化**：因子库 + 知识库接入，把散落的投研直觉与研究资料沉淀为可复用、可审计的因子资产。
- **合规友好**：定位为研究辅助而非自动交易执行，契合监管"扶优限劣"与程序化交易规范导向。

## 十、风险与对策

- **回测严谨性风险**：LLM 可能生成有前视偏差或无法复现的因子代码。对策：强化回测约束校验、代码沙箱、结果可复现与人工终审环节。
- **监管合规风险**：程序化交易与 AI 投顾监管趋严。对策：明确"研究辅助、不自动下单"定位，保留决策留痕与合规说明。
- **模型依赖与成本风险**：依赖外部 LLM API。对策：支持 DeepSeek / Ollama 等本地与低成本模型，降低单一供应商依赖。
- **竞争风险**：巨头云量化平台与开源 Agent 持续演进。对策：以"因子闭环 + 严谨验证"为核心护城河，深耕机构级指标与因子库资产。

## 十一、发展路线图

- **近期（0–6 月）**：完善因子精炼厂与回测指标健壮性，上线 HF Space Demo 与开源社区版，积累种子用户与因子库。
- **中期（6–18 月）**：推出个人订阅与团队版，接入更多 LLM 与另类数据（舆情/事件/一致预期，呼应白皮书 22.49% 事件型数据趋势），构建因子超市。
- **远期（18 月+）**：私有化/API 授权，知识库深度集成，向"智能择时与动态调仓、可解释性风控"等白皮书下一代方向延展，探索多资产与出海本地化适配。

## 十二、结论

中国量化投资在 2025—2026 年迈入"3 万亿时代"，行业增量巨大但深陷 Alpha 衰减、策略同质化与因子拥挤的结构性矛盾。《2024-25 年度中国量化投资白皮书》明确将"AI 全流程自动化"与"AI 自主生成逻辑"列为机构最高优先级方向。FactorGPT 以"自然语言→因子代码→严谨回测→精炼优化→因子库"的闭环，精准命中这一需求空白，并在开源金融 Agent 普遍缺乏因子验证闭环的竞争格局中建立了差异化护城河。结合清晰的梯度商业模式与合规友好的定位，FactorGPT 具备从开发者社区走向商业化落地的可行路径。
